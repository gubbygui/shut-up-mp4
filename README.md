# Shortcutter
A small Python "Video Editor" that lets you perform certain everyday tasks on videos, like shortcuts!

# FEATURES
Barely any... It can just mute your videos.
# Infos
This project uses the moviepy libary!
I made this because the steam clipping app always contained my mic and i didnt want to always cut it out manually or go on a website.
Having a lightweight exe on your desktop is much easier for that imo :)
