# Shut Up Mp4!
A small Python "Video Editor" that lets you mute videos quickly and locally.

## FEATURES
Barely any... It can just mute your videos locally without going on some sketchy site that probably steals it and feeds it into ai lmao.
## Infos
This project uses the moviepy libary!
I made this because the steam clipping app always contained my mic and i didnt want to always cut it out manually or go to a fucking site.
Having a lightweight program that just does the job is much easier for that imo :)
